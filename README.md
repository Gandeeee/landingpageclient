# Pande Suastika - Bali & Indonesia Tour Guide Profile & Link Tree

A modern, high-performance landing page and Link Tree profile for **Pande Suastika**, private tour guide and local host in Bali with over 10 years of hospitality experience.

## ✨ Features

- **Full-Bleed Oceanic Visuals:** High-definition Nusa Penida aerial panorama with sunny tropical tones.
- **Google Sans Typography:** Clean geometric typography powered by self-hosted `@fontsource/google-sans-flex`.
- **Frosted Glassmorphism:** Custom multi-layer backdrop-blur cards with responsive borders and shadows.
- **React Bits Interactive Animations:**
  - **`SplitText`:** Scroll-triggered per-character reveals via GSAP & ScrollTrigger.
  - **`SpotlightCard`:** Cursor-tracking radial luminescence on contact and booking cards.
  - **`BlurText`:** Smooth blur-to-sharp staggered entrance for hero typography.
  - **`ShinyText`:** Shimmering gradient animation for experience badges.
- **Link Tree Integration:** Direct links to WhatsApp (`wa.me`), Instagram, LinkedIn, and **Infinity Photo** (`infinityphoto.netlify.app`).

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS 3
- **Animations:** Framer Motion & GSAP
- **Icons:** Lucide React & Custom Brand SVG Icons

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
